Introduction

A step-by-step demonstration of the developed model is provided through three case studies, designed to progressively evaluate the predictive value of key model components.

  1. Prediction based on structural similarity: The retention factors for imipramine (structurally similar) and ribitol (structurally dissimilar) are predicted using measurements from desipramine using the developed model. This assesses how effectively the model leverages structural similarity for prediction, as imipramine’s retention factor is expected to be more accurately predicted than ribitol’s.

  2. Assessment of individual measurements: The previous prediction is repeated, but with an additional single experimental measurement provided for both imipramine and ribitol. This evaluates the added predictive value of incorporating individual experimental data.

  3. Removal of the similarity matrix: Predictions are performed again, but this time with the similarity matrix excluded from the model. This quantifies the specific contribution of the structural similarity data to the predictive accuracy.

real matrix_normal_lpdf(vector x, vector mu, matrix L_K, matrix L_Omega) {
    int n = rows(L_K); 
    int m = rows(L_Omega);  

    vector[n * m] z = x - mu;
    matrix[n, m] Z = to_matrix(z, n, m);

    matrix[n, m] W = mdivide_left_tri_low(L_K, Z);     // Solve L_K * W = Z
    matrix[m, n] V = mdivide_left_tri_low(L_Omega, W'); // Solve L_Omega * V = W'
    real quad_form_x = dot_self(to_vector(V));

    real log_det_K = 2 * sum(log(diagonal(L_K)));
    real log_det_Omega = 2 * sum(log(diagonal(L_Omega)));
    real log_det = m * log_det_K + n * log_det_Omega;
    real constant = -0.5 * n * m * log(2.0 * pi());

    // Final log-likelihood
    return constant - 0.5 * (quad_form_x + log_det);
  }

  vector funlogki(real logkw, real S1, real S2, vector fi) {
    int d = num_elements(fi);
    vector[d] logki = logkw - S1 * (1 + S2) * fi ./ (1 + S2 * fi);
    return logki;
  }
}

# Introduction

A step-by-step demonstration of the developed model is provided through three case studies, designed to progressively evaluate the predictive value of key model components.

1.  Prediction based on structural similarity: The retention factors for imipramine (structurally similar) and ribitol (structurally dissimilar) are predicted using measurements from desipramine using the developed model. This assesses how effectively the model leverages structural similarity for prediction, as imipramine's retention factor is expected to be more accurately predicted than ribitol's.

2.  Assessment of individual measurements: The previous prediction is repeated, but with an additional single experimental measurement provided for both imipramine and ribitol. This evaluates the added predictive value of incorporating individual experimental data.

3.   Removal of the similarity matrix: Predictions are performed again, but this time with the similarity matrix excluded from the model. This quantifies the specific contribution of the structural similarity data to the predictive accuracy.
