Introductions

A step-by-step demonstration of the developed model’s application is provided through three case studies. -In the first case study, the retention factors of imipramine and ribitol are predicted based on desipramine measurements, allowing assessment of the predictive contribution of structural similarity—relevant for imipramine (structurally similar) but not for ribitol (structurally dissimilar). -In the second case study, the same prediction is performed using desipramine measurements supplemented with a single experimental measurement for ribitol and imipramine. -In the third case study, the similarity matrix is excluded from the predictions.

This series of analyses evaluates the additional predictive value gained from incorporating individual experimental measurements and the similarity matrix.

Initialize variables and parameters

Code 
nObs <- length(data$ID)
nAnalytes <- length(unique(data$ID))
start <- (1:nObs)[!duplicated(data$ID)]
end <- c(start[-1] - 1, nObs)
nK = ncol(functional_groups)

init_aprox <- data %>%
  group_by(ID) %>%
  summarise(
    S1 = if_else(n() == 1,-16,polyfit(fi / (1 + 2 * fi), logk, 1)[1]),
    logkw = if_else(n() == 1,polyfit(-16 * fi / (1 + 2 * fi), logk, 0), 
                             polyfit(fi / (1 + 2 * fi), logk, 1)[2]),
    S2 = 2) %>%
  ungroup() %>%
  select(logkw, S2, S1) %>%
  mutate(S1 = -S1 / (1 + 2))

idxcv = which(data$ID==3) # imipramine

datastruct <- with(data,
                  list(nAnalytes=length(unique(data$ID)),
                       nObs=length(data$ID),
                       analyte=match(data$ID, unique(data$ID)),
                       fi=data$fi,
                       logPobs=descriptor_df$LogP,
                       nK = nK,
                       fgrp = functional_groups,
                       similarity_x = similarity_matrix,
                       start = start,
                       end= end,
                       nObscv = length(idxcv),
                       idxcv = idxcv,
                       logkobs=logk,
                       run_estimation=1))

# initialize the values for each variable in each chain:
init <- function(){
  list(param = cbind(init_aprox$logkw,init_aprox$S1),
       pilogkw = rep(0,nK),
       piS1 = rep(0,nK)
  )
}

Case study 1:

QSRR and similarity matrix for imipramine and ribitol. The data for desipramine used for predictions.

The green area represents population predictions for future observations based solely on population-level parameters and predictors, without any individual-level data. The purple area represents individual predictions, conditional additionally on the retention measurements presented in red. All observation are presented as closed white symbols.

Code 
p <- fit$draws()%>% 
  as_draws_df()%>%

# Introductions

A step-by-step demonstration of the developed model’s application is provided through three case studies.
-In the first case study, the retention factors of imipramine and ribitol are predicted based on desipramine measurements, allowing assessment of the predictive contribution of structural similarity—relevant for imipramine (structurally similar) but not for ribitol (structurally dissimilar).
-In the second case study, the same prediction is performed using desipramine measurements supplemented with a single experimental measurement for ribitol and imipramine.
-In the third case study, the similarity matrix is excluded from the predictions.

This series of analyses evaluates the additional predictive value gained from incorporating individual experimental measurements and the similarity matrix.

```{r stan-setup}
nObs <- length(data$ID)
nAnalytes <- length(unique(data$ID))
start <- (1:nObs)[!duplicated(data$ID)]
end <- c(start[-1] - 1, nObs)
nK = ncol(functional_groups)

init_aprox <- data %>%
  group_by(ID) %>%
  summarise(
    S1 = if_else(n() == 1,-16,polyfit(fi / (1 + 2 * fi), logk, 1)[1]),
    logkw = if_else(n() == 1,polyfit(-16 * fi / (1 + 2 * fi), logk, 0), 
                             polyfit(fi / (1 + 2 * fi), logk, 1)[2]),
    S2 = 2) %>%
  ungroup() %>%
  select(logkw, S2, S1) %>%
  mutate(S1 = -S1 / (1 + 2))

idxcv = which(data$ID==3) # imipramine

datastruct <- with(data,
                  list(nAnalytes=length(unique(data$ID)),
                       nObs=length(data$ID),
                       analyte=match(data$ID, unique(data$ID)),
                       fi=data$fi,
                       logPobs=descriptor_df$LogP,
```
